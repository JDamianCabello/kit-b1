Condicionales: 0, 1 y 2

Si pasa X, entonces Y. Cada tipo tiene sus tiempos fijos.

If it will rain...
If it rains, ...

1Uso

Zero

  • Verdades siempre ciertas

First

  • Algo posible en el futuro

Second

  • Algo imaginario o poco probable

2Forma

Zero

If + presente, presente

First

If + presente, will + verbo

Second

If + pasado, would + verbo

3Ejemplos

Zero

  • If you heat ice, it melts.

First

  • If it rains, we'll stay at home.

Second

  • If I had more money, I would travel more.

4Detalles

  • unless = if not: I won't go unless you come.
  • Segundo condicional: If I were you, I'd... (para dar consejos)
  • Nunca will ni would detrás de if.

Ponlo en práctica

Los fallos se guardan para que los repases.
